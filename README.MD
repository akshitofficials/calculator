# 🧮 Simple Calculator

A simple and interactive **Calculator Web Application** built using **HTML, CSS, and JavaScript**. It performs basic arithmetic operations through a clean and easy-to-use interface.

## 🚀 Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Decimal calculations (`.`)
- Clear button (`C`)
- Simple and clean user interface
- Instant calculation results

## 🛠️ Technologies Used

- **HTML5** – Used to create the structure of the calculator
- **CSS3** – Used for styling and arranging the calculator buttons
- **JavaScript** – Used to handle calculations and user interactions

## 📂 Project Structure

```text
Calculator/
│
```

## ⚙️ How It Works

1. Click the number buttons to enter values.
2. Select an arithmetic operator such as `+`, `-`, `*`, or `/`.
3. Enter the next number.
4. Click `=` to calculate and display the result.
5. Click `C` to clear the display and start a new calculation.

## 💻 Run Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Open the project folder and run:

```text
index.html
```

You can simply open `index.html` in any modern web browser.
